## Reflexão Final

1. **Qual a importância do Git para desenvolvimento de software?**
   O Git permite controlar o histórico de alterações do código, trabalhar em equipe sem sobrescrever o trabalho de outros desenvolvedores, reverter erros facilmente e manter um registro detalhado de todas as modificações no projeto.

2. **Como o uso de branches pode ajudar no trabalho em equipe?**
   As branches permitem que diferentes membros da equipe trabalhem em recursos ou correções de bugs de forma isolada, sem afetar o código principal (`main`) até que a funcionalidade esteja testada e pronta.

3. **Por que é importante escrever mensagens de commit claras?**
   Mensagens claras ajudam a entender rapidamente o que foi feito em cada alteração sem precisar ler o código modificado, facilitando auditorias e a identificação de bugs no histórico.

4. **Quando você usaria o arquivo .gitignore?**
   O `.gitignore` deve ser usado para evitar que arquivos temporários, pastas de dependências (como `node_modules`), arquivos de configuração pessoal de IDEs e, principalmente, arquivos com credenciais/senhas sensíveis sejam enviados ao repositório público.

5. **Como o histórico de commits do seu repositório demonstra seu aprendizado?**
   O histórico funciona como uma linha do tempo mostrando cada etapa concluída, a evolução do projeto e o domínio progressivo dos comandos e conceitos do Git ao longo das tarefas.
